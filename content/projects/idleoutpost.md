Idle Outpost is a mobile game by Rockbite Games set around building and expanding a post-apocalyptic trading post. 

The game received wide recognition with almost 50 million downloads on stores and created a series of apocalypse-themed games with similar mechanics. At Rockbite Games I was a part of Idle Outpost Client Team, focused on feature development, and later was working on Performance and Production Maintenance. 
You can read more about the project [here](https://rockbitegames.com/games/idleoutpost).

SlateLua is a small toolkit for Love2D game development. It is designed as a collection of modules that can be used together or required independently. The project is still in an experimental state and is mostly used for fast prototyping with Lua. You can check out the source code [here](https://github.com/slateblua/slatelua).

## Tech

Built with Lua for Love2D.

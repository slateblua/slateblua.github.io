Meent is a productivity app project that allows to set blocking timers for selected apps. The app structure includes onboarding, a main dashboard, focus limit management, reports, and settings.
Meent uses Accessibility Services on Android for blocking selected applications during focus time. 

## Links

- [GitHub repository](https://github.com/slateblua/meent)

## Highlights

- Onboarding and main app navigation.
- Dashboard, focus limit, reports, and settings screens.
- Data layer with app database and user preferences storage.

## Tech

Built with Kotlin, Compose, Koin and Orbit.
